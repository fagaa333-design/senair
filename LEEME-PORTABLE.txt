SENAIR - Proyecto
=================

El proyecto incluye:
- FRONTEND: paginas, estilos, scripts e imagenes.
- BACKEND: servidor Node.js + Express y API REST (vuelos, reservas, autenticación).
- database\senair.sql: esquema completo MySQL (tablas users, flights, reservations y datos iniciales).

Configuración de la Base de Datos:
1. Inicia tu servidor MySQL (XAMPP localmente o servidor de hosting/nube).
2. Importa el archivo database\senair.sql en tu MySQL.
3. En la carpeta BACKEND, crea o edita el archivo .env con tus credenciales:
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD=
   DB_NAME=senair
   JWT_SECRET=tu_clave_secreta

Para ejecutar:
1. Instala Node.js LTS desde https://nodejs.org/
2. Ejecuta instalar-dependencias.bat (o 'npm install' en BACKEND).
3. Ejecuta iniciar-senair.bat (o 'npm start' en BACKEND).
4. La pagina se abrira en http://localhost:3000/html/index.html
